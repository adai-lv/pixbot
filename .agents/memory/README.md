# Memory 编写规范与模板

> 本文件只规定每日 memory 的组织、任务块模板和内容边界。任务恢复、更新、对账与收尾流程以 [AGENTS.md](../../AGENTS.md) 为唯一权威来源；实例导航与跨文档证据分工统一见[工作文档索引](../README.md)。

## 职责与边界

每日 memory 保存任务未完成时的最后已知恢复中间态，并在任务完成后将原任务块转换为有参考和学习价值的摘要与经验索引。每日文件不是当前行为、技术设计或长期规则的权威来源，也不替代 Spec、Plan、Issue、TODO 或 Git 历史。

## 文件与恢复规则

- 每个实际开始的任务都在 `.agents/memory/YYYY-MM-DD.md` 建立一个二级标题任务块；文件日期取任务开始时的本地日期，同日任务按开始顺序排列。
- 每日文件使用日期作为 H1，任务名称使用 H2。任务块只更新本任务并保留其他任务。
- 跨天不复制或移动任务块，始终更新开始日期文件中的原任务块；跨天但恢复信息没有变化时，不因日期本身重写任务块。
- 恢复时不能只读取当天文件；应查找状态为“进行中”“中断”或“待核对”的任务块，再核对关联文档、实际文件和 Git 工作树。
- `进行中` 表示正在执行，`中断` 表示已停止且记录了恢复位置，`待核对` 表示可能已产生改动但尚未确认实际结果。
- 快照是最后已知状态，不保证捕获硬中断后的变化；恢复前必须对账，不得盲目续跑或重放副作用命令。
- 总索引只链接本编写规范，不逐日登记每日记忆文件。
- 既有任务块不批量改写，旧的固定“中断信息：无”可以继续保留；新规则作用于新任务及后续实际更新，新旧记录共存不视为格式错误。

## 检查点与写入预算

写入时机遵循 AGENTS.md 的检查点规则，填写时同时控制写入次数和单次内容：

| 写入情形 | 记录重点 |
|---|---|
| 任务开始 | 关联文档、当前位置和第一个具体下一步 |
| 关键步骤使恢复游标、下一步或未核对改动发生实质变化 | 最新已验证位置及新的恢复动作，不同步每个 P 步骤 |
| 重要副作用前、获知异常或中止 | 必要改动或副作用、精简异常摘要及恢复核对项 |
| 最终收尾 | 实际结果、验证证据入口或关键结果，以及可复用经验 |

- 同一检查点命中多个触发原因时只写一次，不为“完成步骤”和“开始下一步”分别更新。
- 只有时间、措辞或排列变化时不写；最后更新时间随真实快照变化更新，不单独刷新。
- 简单且无额外副作用的单会话任务通常只需开始与收尾两次写入；复杂任务按恢复需要增加，不设机械次数上限，也不得省略必要快照。
- 共享每日文件时只更新本任务块；未核对改动只记录本任务拥有或产生的改动与副作用，其他任务仅在影响本任务恢复时简要提及。

## 内容预算与证据分工

- 最后确认位置只保留最近一个已验证游标，可引用 P／AC 编号、文件或操作，不保留过程流水。
- 下一步只写一个具体、可执行的恢复动作，不同时堆放多个备选方向。
- 恢复前核对只写本任务特有的额外事项；通用关联文档、实际文件和 Git 对账不在每个任务块重复展开。
- 任务摘要只写实际结果和必要偏差；验证摘要保留证据入口或关键真实结果及例外；经验索引只保留可复用提示及权威文档链接。

## 未完成模板

普通进行中任务使用七个核心字段；中断信息按条件添加：

```markdown
## <任务名称>

- 状态：进行中 / 中断 / 待核对
- 最后更新时间：<带时区偏移的 ISO 8601 时间>
- 关联文档：<Spec、Plan、Issue 的相对链接；无则说明>
- 最后确认位置：<最近一个已验证游标；可引用 P／AC 编号、文件或操作，不保留过程流水>
- 下一步：<一个具体、可执行的恢复动作>
- 未核对改动：<本任务未验证的改动或副作用；无则说明>
- 中断信息：<仅中断、待核对或存在异常时填写原因或精简错误摘要；否则省略>
- 恢复前核对：<本任务特有的额外核对；无额外项时写“无额外项，通用核对仍须执行”>
```

中断或待核对必须保留最后已知状态、原因、未核对改动和恢复核对；重要副作用前的快照不能因写入预算而省略。验证失败不得转为已完成。

## 最终态模板

任务完成验收并回写关联工作文档后，将原任务块原地改为以下六个字段：

```markdown
## <任务名称>

- 状态：已完成 / 已关闭
- 完成时间：<进入最终态的带时区 ISO 8601 时间；已关闭时表示关闭入账时间>
- 关联文档：<Spec、Plan、Issue 的相对链接；无则说明>
- 任务摘要：<实际结果及必要偏差；已关闭时首先说明关闭原因，不复述过程背景>
- 验证摘要：<有验收文档时引用其结果并补充关键例外；无验收文档时列出关键检查与真实结果；未执行项不得省略>
- 经验索引：<一句可复用提示及权威文档链接（规则→AGENTS.md、决策→docs/decisions.md、排障→docs/runbook.md）；没有可复用经验时写“无”>
```

- 经验索引应能说明“下次什么时候有用”，不能只把本任务相关文档重新列一遍；常规任务没有新经验时写“无”，不强迫提炼。
- 转换时删除最后确认位置、下一步、未核对改动、中断信息和恢复前核对等中间态字段，保留有参考价值的最终结果。
- 已关闭任务必须记录关闭原因及实际未验证项，不得写成已完成；仍有恢复可能的暂停任务继续使用未完成模板。

## 内容约束

- 不复制 Plan 步骤表、完整日志、Spec 背景或权威文档正文，不保存无参考价值的临时命令输出。
- 不记录密钥、真实用户数据、本地会话正文或不必要原始日志；异常只保留恢复所需的安全摘要。
- 文档使用一个 H1，标题逐级递进，代码围栏标注语言，链接路径大小写与磁盘一致。
