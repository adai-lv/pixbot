## 证据分工

同一条执行规则和同一份证据只保存在一个文档，其余位置仅使用链接指路：

| 文档 | 唯一保存 |
|---|---|
| Spec | 验收结论（按 AC 编号的通过／失败／未执行／不适用与最终证据） |
| Plan | 步骤级执行证据与完整检查结果 |
| Issue | 问题证据、根因、修复范围与直接修复的验收结论 |
| Memory | 未完成时的最后已知恢复中间态；完成后的任务摘要、验证摘要与经验索引 |
