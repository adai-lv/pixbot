# Plans 编写规范

> 本目录保存已确认 Spec 的按需实施计划。项目规则与 DoD 以 [AGENTS.md](../../AGENTS.md) 为唯一权威来源；本文件只规定 Plan 的组织、编写和模板。实例导航与跨文档证据分工统一见[工作文档索引](../README.md)。

## 职责与边界

Plan 回答“按什么顺序、修改哪些文件、如何逐步验证、实际执行结果是什么”，用于把已确认 Spec 转换为可执行步骤，并保存步骤级执行历史。Plan 不重新定义需求、验收标准或长期架构，也不复制 Spec 的目标、背景、目标设计和验收正文。

每份 Plan 必须关联一份已确认 Spec；创建门槛、Issue 升级规则和跨文档证据分工见 [AGENTS.md](../../AGENTS.md) 流程第 4、5 条、[Spec 规范](../specs/README.md)和[工作文档索引](../README.md)。

## 命名与关联

- 文件名为 `YYYYMMDDHH-plan-<topic>.md`，例如 `2026110707-plan-agent-document-lifecycle.md`。
- 完整时间前缀和 `<topic>` 必须与关联 Spec 完全一致，`<topic>` 使用小写 kebab-case；Plan 沿用 Spec 首次创建时的本地小时，不重新取小时。
- Spec 文件名为 `YYYYMMDDHH-design-<topic>.md`，Plan 开头通过 `../specs/YYYYMMDDHH-design-<topic>.md` 链接关联 Spec。
- Spec 与 Plan 一对一；确需拆分时，先调整 Spec 边界，不建立多份计划共同修改同一范围。

## 编写与执行流程

1. 阅读关联 Spec，确认目标、范围、设计和验收没有未决项后再开始。
2. 将工作拆为有序的小步骤，使用 `P-01`、`P-02` 等在 Plan 内唯一的稳定编号，并明确依赖关系；一步只完成一件可验证的事。
3. 实施前建立全部 Spec AC 到 P 步骤的覆盖表。没有覆盖的必填 AC 必须补步骤，不得留到收尾时补写形式化映射。
4. 涉及代码时按 AGENTS.md 先写或更新失败测试，再实施并运行对应验证；预期失败与异常失败分开记录。
5. Plan 状态只使用“草稿／待执行／进行中／已完成／已中止”。执行时如实更新步骤状态，不预先填写完成结果。
6. 发现范围、设计或验收需要变化时暂停实施，先更新并重新确认 Spec，再同步 Plan；Plan 不得自行扩大范围。
7. 收尾执行 Spec 和 AGENTS.md 要求的完整验证，按覆盖表记录证据位置并回写 Spec 收尾记录；完成后 Plan 作为执行历史保留，当前行为仍以代码和测试为准。

## 步骤与验证粒度

- 每步包含状态、依赖、文件、操作、验证、预期和实际结果。文件尚不存在时明确写“新增”，删除或重命名也应明确标注。
- 相关命令和同一验证单元可以合并在一步，不为机械命令过度拆分；高风险、不可逆或需要独立确认的操作单独成步。
- 步骤只使用“未开始／进行中／已完成／已跳过”状态字段，不再使用复选框维护第二份步骤状态。
- 验证只写必要的命令、测试名称或受控检查，不使用“确保正常”等模糊表述，也不复制其他文档模板、长段实现代码或完整日志。
- 实际结果记录真实结果、关键退出状态、测试名或证据位置。未执行写“未执行”，失败保留失败摘要，均不得写成通过。
- 验证失败的步骤不能标为“已完成”；继续修复时保持“进行中”，停止实施时按计划状态记录“已中止”。
- “已跳过”必须说明原因。跳过导致必填 AC 没有覆盖时不得完成 Plan，须先调整并重新确认 Spec。

## 验收覆盖与最终验证

验收覆盖表在实施前建立，执行后补充真实结果与证据位置：

| Spec 验收 | 覆盖步骤 | 结果与证据位置 |
|---|---|---|
| AC-01 | P-01 | 见 P-01 实际结果 |
| AC-02 | P-02、P-03 | 最终异常测试或检查的位置 |

- 每条 AC 至少映射一个 P 步骤，一个步骤也可覆盖多条 AC；映射只写覆盖关系和证据位置，不复制验收正文。
- 最终验证另列必须整体重跑的完整检查，防止只执行局部步骤而遗漏全量回归。必填 AC 存在失败、未执行或无覆盖时，Plan 不得标为“已完成”。

## 内容与步骤约束

- 步骤按实际执行顺序排列，依赖未完成的步骤不得提前执行。
- 测试数据、命令和路径使用占位或仓库内安全示例，不包含密钥和真实用户数据。
- 按实际情况增删模板步骤，不在正式 Plan 中保留空白示例步骤或提示文字。
- 文档使用一个 H1，标题逐级递进，代码围栏标注语言，链接路径大小写与磁盘一致。
