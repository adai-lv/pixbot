## 当前排障入口

本地开发使用 Rust 1.93 或更高版本。以下命令的工作目录为仓库根目录下的 `apps/`：

```bash
cargo run -p cli -- -p "你好"
```

| 现象 | 当前解释与处置 |
|---|---|
| CLI 参数解析失败 | 核对实际传入参数与 `apps/crates/cli/src/cmd.rs`；不按目标设计猜测已支持的参数 |
| Cargo 构建失败 | 确认工具链满足 Rust 1.93 MSRV，再依据编译错误定位工具链、依赖或代码问题 |
| 其他运行故障 | 按已复现事故补充，不在本文猜测命令 |

排障记录只保留已复现的现象、实际原因、可执行处置和验证结果；不得记录密钥、token、真实用户数据或本地会话内容。
